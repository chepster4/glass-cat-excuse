## The entry

> The glass parked itself in my sunbeam and refused to move, so I towed it off the table myself.

The cat's defence, five seconds after sweeping the glass off the table: the glass
was an illegally parked car in the cat's sunbeam, and the cat towed it. No apology,
no remorse, no gravity, no slippery edge — just a cat enforcing parking rules in
its own territory.

## What it does

`main.ts` (Node 22, standard library only, no network access) writes that single
sentence to `/output/entry.txt`. The program is fully deterministic: every run
produces the exact same bytes — 94 characters, one sentence, no trailing newline.

## How to run

```sh
node main.ts
```

The sentence is written to `/output/entry.txt`.
